# Таро · Справочник значений карт

Статическое веб-приложение: все 78 карт колоды Universal Waite с трактовками прямого и перевёрнутого положений.

## Запуск

Работает офлайн — просто откройте `index.html` в браузере.

Либо через локальный сервер:

```bash
cd tarot-guide
python3 -m http.server 8080
# → http://localhost:8080
```

## Структура

```
index.html          — единственная страница (вкладки мастей, поиск, модалка карты)
css/style.css       — тёмная эзотерическая тема
js/app.js           — логика: сетка, фильтры, поиск, модалка, переворот карты
js/data.js          — СГЕНЕРИРОВАННЫЕ данные 78 карт (не редактировать вручную)
data/*.json         — источник правды по контенту и Golden Dawn
img/cards/          — 78 изображений карт + card-back.webp (рубашка)
fonts/              — локальный Cormorant Garamond (woff2, кириллица+латиница)
build_site.py       — полная сборка и проверка сайта одной командой
merge_data.py       — пересборка js/data.js из data/*.json
check_site.py       — проверка ссылок, версий, JavaScript и 40 блоков Golden Dawn
optimize_images.py  — создание оптимизированных WebP без удаления JPG-исходников
cards_manifest.txt  — список id карт
```

## Как править контент

1. Отредактируйте нужный JSON в `data/` (например, `data/wands.json`).
2. Пересоберите весь сайт: `python build_site.py`.
3. Обновите страницу в браузере.

Сборка завершится ошибкой, если потеряна ссылка, изображение, карта или хотя бы
один из 40 блоков Golden Dawn. Для гарантированного обновления опубликованного
сайта ресурсы подключаются с единой версией кеша.

## Возможности

- Вкладки: Старшие арканы / Жезлы / Кубки / Мечи / Пентакли
- Поиск по названию (рус/англ), масти и ключевым словам — по всем 78 картам
- Страница карты: стихия, астрологические соответствия, анимация переворота
- Для каждого положения: краткое значение, ключевые слова, архетип, быт, работа/карьера, отношения, здоровье, эзотерика
- Для Туза–Десятки каждой масти: отдельный блок трактовки ордена «Золотая Заря»
- Полностью офлайн, без внешних зависимостей, mobile-first
